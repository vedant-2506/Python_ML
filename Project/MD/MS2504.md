
# Title
Rule-Based ATS Score Calculation

## Description
The system uses predefined rules and criteria to identify relevant information from the resume and job description and calculate an overall ATS score.

Current work includes designing and implementing rules for:
keyword matching
Education matching
Work experience matching
Text similarity
Certification matching
Job description and title requirement matching
Overall ATS score calculation


## Data
 The system uses candidate resumes and job descriptions as input data.
 The data is collected form the Kaggle having approximately 2000 resumes.

## Results
 The system generates an ATS score based on the degree of match between the candidate's resume and the job description.
