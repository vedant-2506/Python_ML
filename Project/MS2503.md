## **Date:** 24 Sep 2026


**Subject:** **JSON Structure Issues and Required Code Changes**

* The previous code for the `rankresume` project is working perfectly, but there are some problems faced and specific changes required in the code.


* The Job Description (JD) JSON format uses `expected_certificate` and does not include an extra-skill field.


* In the resume JSON, the section currently written as `achievements` should be corrected and written as `certificate`.


* Extracurricular certificates and other notable achievements—such as being a state-level champion or securing 1st rank in a hackathon—should be added to this section.


* There are parsing mistakes in some of the generated JSON files where projects are not added perfectly.


* Specifically, a mismatch occurs in some cases where the project description is incorrectly placed into the project title field.


* In certain resumes, certificates are explicitly mentioned, but the corresponding certificate section in the JSON remains blank.


* In one instance, a JD explicitly required students to have marks of 60% and above, but this 60% criterion was not captured in the JSON's expected percentage field.


* All of these parsing and structural issues need to be checked and resolved.
